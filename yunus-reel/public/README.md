# Audio (optional)

- `voiceover.mp3` — drop your Arabic voiceover here. If it is missing the reel
  renders silently (a "voiceover placeholder" tag shows only in Remotion Studio).
- `sfx/waves.mp3`, `sfx/thunder.mp3`, `sfx/wind.mp3` — optional ambience; cue
  times live in `SFX` in `src/timeline.ts`. Missing files are skipped.

No instrumental music is used.
